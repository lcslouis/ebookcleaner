# EbookCleaner

A Windows desktop app for fetching, cleaning, and exporting web novels as EPUB files.

## Download

**[Go to Releases →](https://github.com/lcslouis/ebookcleaner/releases)**

| Download | Description |
|----------|-------------|
| **Full Bundle** | EbookCleaner + Provider Studio in one ZIP (recommended) |
| **EbookCleaner** | Main app with AI cleaning, site login browser, and plugin support |
| **EbookCleaner Lite** | Lightweight version — fetch, clean with rules, and export. No AI or browser |
| **Provider Studio** | Standalone tool for creating and testing custom site plugins |

No Python required — just download, extract, and run `EbookCleaner.exe`.

## Features

- Fetch chapters from web novel sites (Royal Road, WordPress-based sites, and more via plugins)
- Clean and reformat chapter text with configurable rules
- AI-powered rewrite and cleanup (requires an API key — Claude or Gemini)
- Export to EPUB
- Batch chapter rename with format presets
- Community plugin registry for adding new sites
